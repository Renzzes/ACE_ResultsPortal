BUILD A PRODUCTION-READY WEB APPLICATION FOR ACE MEDICAL CENTER CEBU

PROJECT NAME:
ACE Results Portal

PROJECT OVERVIEW

Develop a secure, standalone web application that allows ACE Medical Center Cebu to upload, manage, and release patient laboratory, radiology, and diagnostic results online.

This system WILL NOT be integrated with our existing Hospital Information System (HIS).

Our current HIS already generates a unique Patient ID.

Hospital staff will manually create patient records in the portal using the Patient ID generated by the HIS.

The system must be designed with healthcare-grade security, privacy, accountability, and audit controls.

PRIMARY OBJECTIVES

1. Allow hospital staff to upload patient results.
2. Allow patients to securely access and print their own results online.
3. Allow authorized physicians and hospital staff to access patient results.
4. Maintain strict compliance with data privacy and security standards.
5. Create a complete audit trail of all activities.

Patient Record Creation:

Required Fields:

* Patient ID (from HIS)
* Last Name
* First Name
* Middle Name
* Date of Birth
* Mobile Number (optional)
* Email Address (optional)

Upon patient creation:

Generate a UNIQUE ACCESS CODE.

Example:
ACE-8F9X-2K7P

The access code must:

* Be randomly generated
* Be unique
* Be difficult to guess
* Be stored securely

Staff can provide this code to patients upon release of results.

SECURITY REQUIREMENTS

THIS IS THE HIGHEST PRIORITY.

Implement:

* HTTPS Only
* Secure Authentication
* Password Hashing (Argon2 or Bcrypt)
* Role-Based Permissions
* Session Timeout
* CSRF Protection
* XSS Protection
* SQL Injection Protection
* Rate Limiting
* CAPTCHA After Failed Attempts
* Secure File Upload Validation
* Virus Scanning of Uploaded Files
* Secure File Storage
* No Public File URLs
* Temporary Signed Download Links
* Encryption At Rest
* Encryption In Transit

Brute Force Protection:

* 5 Failed Attempts
* 15 Minute Lockout
